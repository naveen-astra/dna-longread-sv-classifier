Long-read structural variant classifier

Structural variants (SVs) are DNA changes of 50 bases or more. Long-read callers such as Sniffles2 and cuteSV find them but also report many false calls. This project trains Random Forest and XGBoost classifiers to separate real calls from false ones and tests them against the GIAB HG002 truth set.

Pipeline

One Snakemake workflow runs from raw reads to a scored callset. The classifier filters the callers' candidates; it does not replace the callers.

  1. ReadsGIAB reads for selected regions, quality-checked with NanoPlot.
  2. AlignmentMinimap2 aligns reads to GRCh38.
  3. CallingSniffles2 and cuteSV propose candidate SVs.
  4. Mergingtruvari collapse merges the two callsets.
  5. Features33 measurements per candidate.
  6. Labelstruvari bench matches candidates to GIAB v5.0q.
  7. ModelsRandom Forest and XGBoost, split by chromosome.
  8. OutputsScored VCF, benchmark, SHAP explanations, report.

Tools: minimap2, samtools, bcftools, NanoPlot, Sniffles2, cuteSV, truvari, scikit-learn, XGBoost, SHAP, Snakemake.

Data

Reference: GRCh38. Truth: GIAB HG002 v5.0q. Reads cover selected regions rather than whole genomes.

Only HG002 has SV truth, so the labelled data is split by chromosome.

Features

33 features in four groups. Read evidence and genomic context are independent of the callers; caller evidence and caller-declared features come from the callers' output.

Models

Stage A, real or false, is the main task. Stages B and C predict the SV type.

StageQuestionLabels fromStatus
AIs the call real or false?GIAB v5.0qPrimary result
BDeletion or insertion?GIAB v5.0qSanity check only
CWhich of five types?Caller consensusExploratory

Scores are calibrated. The threshold is chosen on the validation chromosome; the test chromosome is scored once.

Results

Held-out chr22 test windows. Recall counts every real SV, including those neither caller found.
